Our part
Software development and every interaction

We built a session booking system for hands-on programs, now in use at KT AI Station venues. The booking server and its database run on one laptop on site, and visitors reach it through the fixed address in a printed QR code. Capacity is checked again when a booking is confirmed, so no session is overbooked. Bookings, cancellations and message delivery status reach the staff dashboard as they happen.

Key engineering

  • Live operations dashboard over Server-Sent Events, and a local admin server isolated from the public booking server
  • Transactional capacity control, idempotent booking submission and alternative-session suggestions
  • Queued SMS/LMS reminders with per-session early dispatch
  • Fixed QR address on an edge worker, with heartbeat-based registration of the site’s tunnel URL
  • Per-booking portrait consent records that keep the exact wording and time of consent
  • Desktop site server packaged as Windows and macOS installers
