Jimssalabium

A popup kiosk for Jimssalabium, an ENA travel show. It reads the barcodes on two packing cards, matches a destination and prints the result on a receipt.

Client
KT × ENA
Where
KT Gwanghwamun building, Seoul
When
August 2026
Our part
Software development and every interaction

Jimssalabium is an ENA travel show in which four maximalists travel with a single carry-on. For its popup at KT’s Gwanghwamun building we built a 9:16 portrait kiosk. Visitors scan two packing cards one at a time, filling the suitcase on screen, and the pair of cards decides one of eight destinations. Tapping print on the result screen sends a receipt to the thermal printer.

Key engineering

  • 9:16 portrait kiosk web app with CSS keyframe animation
  • HID barcode scanner input and ESC/POS raster receipt printing over direct USB
  • JSON-configured rule engine: 27 card pairs to eight destinations
  • Local server for the receipt-print and statistics APIs, with no internet dependency
  • Usage statistics in a local database by day, destination, card pair and card, with CSV and JSON export
  • Windows installer bundling the Node.js runtime and printer driver, launching the browser in kiosk mode
